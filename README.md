# ProjetoEstoque

Sistema de controle de estoque desenvolvido em **Java**, executado pelo terminal.

Meu primeiro projeto pessoal em Java, desenvolvido para praticar **POO, CRUD, validações e tratamento de exceções**.

## Funcionalidades

* Adicionar produtos
* Listar produtos
* Buscar produto por ID
* Remover produto
* Atualizar nome, preço e quantidade
* Geração automática de IDs
* Validação de dados e tratamento de exceções

## Conceitos praticados

* Java e POO
* Classes, objetos e encapsulamento
* Getters e setters
* `ArrayList`
* `Scanner`
* `switch`, condicionais e loops
* `try/catch`
* `InputMismatchException`
* `IllegalArgumentException`
* CRUD

## Estrutura

* `Produto` → representa os produtos e suas validações.
* `Estoque` → gerencia os produtos e operações do CRUD.
* `Main` → interação com o usuário e menu principal.

## Tecnologias

* Java
* IntelliJ IDEA
* Git/GitHub
